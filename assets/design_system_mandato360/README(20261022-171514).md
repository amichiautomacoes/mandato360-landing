# MANDATO 360 — Design System v1.0

Abra `index.html` no navegador. Não requer servidor ou bibliotecas externas.

## Arquivos
- `tokens.css`: variáveis globais de cores, espaçamento, tipografia, raios e gradientes.
- `components.css`: botões, cards, badges, indicadores, barras e templates de publicação.
- `index.html`: documentação visual, exemplos e playground responsivo.

## Uso
Inclua `tokens.css` e `components.css` no HTML. Utilize classes como `.m360-card`, `.m360-btn`, `.m360-badge`, `.m360-post`, `.m360-highlight`.

## Observações
A estrutura editorial e os nomes dos módulos foram consultados na landing pública em 21/10/2026. Os valores CSS são uma proposta baseada na identidade visual discutida, não uma cópia auditada dos estilos originais. Substitua a assinatura textual demonstrativa pelo arquivo de logo oficial. Gráficos demonstrativos não representam dados reais.
